RaidlandsRoamBots v0.3.34 killfeed + quiet console + clan wars - 2026-07-05

What changed:
- Checked-in RoamBots config is now a staged live-release profile: disabled on reload, target=50, min=0, max=200.
- Added an in-game admin CUI opened with `/raidbots admin`.
- Added `raidbots.ui` as the panel action dispatcher behind the CUI buttons.
- Admin panel tabs now cover overview, population, spawn, AI, utility, rewards, advisor, debug, and danger controls.
- The panel can enable/disable, apply the live 50/200 preset, spawn manual test batches, tune target/min/max, change spawn mode, clear anchor, toggle tactical features, tune key ranges/cooldowns/caps, manage rewards/RP, switch advisor modes, control debug UI, reload config/data, and run emergency cleanup actions.
- Code defaults now match the staged high-cap live config for target/max population, near-player spawn tuning, random fallback, nav sample distance, retry timing, and solo/duo/trio weights.
- Near-player spawning now targets any active non-safe-zone player; the tester-only `ababmxking` anchor is cleared.
- Random land fallback remains disabled so bad/no player-adjacent spawns do not silently become arbitrary map spawns.
- Team weights are back to a normal live mix: solo=55, duo=35, trio=10.
- Debug spawn logs, tactical logs, nameplates, and side panel are off by default.
- Debug console logs are now separated from debug UI and remain off by default; repeated spawn/kit warnings are throttled.
- Different-clan roam bots can now target, damage, and kill each other; same-clan bot damage remains blocked.
- Decision advisor is off/fallback-only by default so release play uses deterministic local tactics and makes no outbound advisor calls unless explicitly configured later.
- Foliage LOS defaults now use a narrower 0.65m cast, require 2 foliage blockers, and allow 24m clear-through distance to reduce firing through brush while avoiding one-branch false negatives.
- Kill chat for tracked roam bot deaths now includes weapon/method/distance, such as `PlayerName killed [NR] LaunchLoot with Assault Rifle from 42m (gunfire).`.
- Bot kills against real players now broadcast to global chat with the same DeathNotes-styled format.
- Different-clan bot-vs-bot kills also broadcast through the same killfeed.
- DeathNotes is suppressed for any death involving a tracked roam bot to avoid duplicate generic scientist/NPC death messages.
- Real players now receive ServerRewards RP for roam bot kills.
- The live config currently awards 5 RP per roam bot kill and sends the killer a short RP confirmation message.
- New config section: `Bot Kill Integration`.
