Raidlands bots debug UI and LiveAdmin command catalog - 2026-07-06

What changed:
- RaidlandsRoamBots v0.3.38 suppresses and destroys the right-side debug panel when common menu/admin CUI commands fire, including Kits editor commands such as `kits.creator`, so the one-second debug refresh does not re-add the side panel above another plugin's menu.
- Explicit close commands such as `kits.close` now actively shorten an existing menu suppression window, so the debug side panel can return shortly after the other menu closes.
- Normal menu commands now use a shorter fallback suppression window if no close command is seen.
- Opening the `/raidbots admin` CUI clears and suppresses the right-side debug panel until the admin CUI is closed.
- LiveAdmin v0.4.5 adds a Commands nav tab with separate Slash Commands and Console Commands pages, filter support, paging, plugin/source columns, and a short cache over the local plugin source scan.
